## 檔案結構

- `index.html`：手機版入口頁
- `style.css`：頁面樣式
- `app.js`：搜尋、篩選、排序與 Google Maps 導航互動
- `data*.js`：景點、美食、咖啡廳與玩水資料
- `.github/workflows/pages.yml`：GitHub Pages 自動部署流程
